The fixed sign outlines are original arrangements of short phrases, converted to vector contours for Three.js extrusion. The fictional hotel reads **El Castillo / RESORT HOTEL**; the source photograph's real hotel wordmark is not copied.

The other fictional brands are **Best Eastern / SEASIDE INN** and **Ethel's / FILLING STATION**. Ethel's name uses Pacifico; the remaining diner, street and hotel lettering uses Anton. Physical signboards provide room around each text line.

“El Castillo” uses [Pacifico](https://github.com/google/fonts/tree/main/ofl/pacifico), and the road lettering uses [Anton](https://github.com/google/fonts/tree/main/ofl/anton). Both use the SIL Open Font License; the accompanying license files preserve their attribution. Only complete sign artwork is stored here, with no browser font request or full font library.
